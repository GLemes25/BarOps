Como um Engenheiro de Frontend e UI/UX, refatore o componente ShoppingListSection para torná-lo interativo, permitindo edição de nomes, quantidades, adição de itens extras e 'exclusão' (riscar itens), mantendo o layout minimalista e garantindo uma impressão (PDF) impecável.

Como este componente usa hooks de estado, garanta que ele tenha 'use client' no topo do arquivo (ou crie um sub-componente client-side se necessário).

Execute rigorosamente os seguintes passos de lógica e design:

Gerenciamento de Estado Local:

Crie um tipo estendido LocalShoppingItem baseado no ShoppingListItem original, adicionando: id (uuid ou string única), originalName, originalQty, isDeleted, isNew, e unitPrice (calculado como estimatedCost / quantityToBuy).

Inicialize um estado const [items, setItems] = useState<LocalShoppingItem[]>(...) mapeando a prop shoppingList original para este novo formato.

Layout Minimalista da Linha (Grid/Flex):

Para cada item, crie um layout flexível.

Nome: Use um <Input> com estilo minimalista (sem bordas visíveis até o hover/focus).

Quantidade: Crie um controle <Button size="icon" variant="ghost"><Minus/></Button> <Input className="w-16 text-center border-none" type="number"/> <Button size="icon" variant="ghost"><Plus/></Button>.

Custo: Recalcule o custo dinamicamente: item.quantityToBuy \* item.unitPrice.

Regras de Cores (Tailwind):

Quantidade maior que originalQty: classe text-emerald-600 dark:text-emerald-400.

Quantidade menor que originalQty: classe text-destructive.

Nome diferente de originalName: classe text-amber-600 dark:text-amber-400.

Item Novo (isNew): texto todo em text-emerald-600 dark:text-emerald-400.

Removido (isDeleted): line-through opacity-50 text-muted-foreground.

Botão de Ação Único (Smart Button):

Avalie se o item foi modificado: const isModified = item.quantityToBuy !== item.originalQty || item.ingredientName !== item.originalName || item.isDeleted;

Se isModified for true (ou se for isNew), exiba um <Button> com o ícone de RotateCcw (Reset) ou Trash (se for novo e quiser apagar de vez). A função de reset deve restaurar os valores originais e setar isDeleted = false.

Se isModified for false, exiba o ícone de Trash (que apenas seta isDeleted = true).

Adição de Novos Itens:

No final da lista, adicione um botão <Button className="w-full border-dashed border-2" variant="ghost"> <Plus/> Adicionar Item Extra </Button>.

Ao clicar, insira um item vazio/editável no estado com isNew: true.

Regras Estritas de Impressão (Print):

Na raiz das linhas ou textos, force cores padrão na impressão: print:text-black print:no-underline.

Oculte itens deletados na impressão: print:hidden na <li> se isDeleted.

Oculte todos os botões (+, -, Reset, Trash, Adicionar) usando print:hidden.

Crucial para Inputs: Inputs não são impressos corretamente. Renderize o valor do <Input> dentro de um <span className="hidden print:inline"> e oculte o input na impressão com print:hidden.

Não adicione comentários explicativos no código e mantenha o uso de componentes do shadcn/ui e lucide-react.
