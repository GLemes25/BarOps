Como um Engenheiro de Frontend Sênior e Especialista em UX/UI, refatore o componente app/events/[id]/event-drinks-section.tsx para abandonar o modelo tradicional de 'Lista + Modal' e adotar o padrão de 'Vitrine Interativa de Cards' (Selectable Gallery).

A nova tela exibirá o catálogo completo de bebidas e permitirá que o usuário adicione ou remova drinks do evento com um único clique no próprio card.

Execute rigorosamente as seguintes instruções:

Remoção do Modelo Antigo:

Remova o estado isAddOpen, o botão de 'Adicionar Drink', o componente <Dialog> e a chamada para o <EventDrinkForm>. Tudo será feito na própria tela.

Estado e Lógica de Seleção:

Adicione um input de busca (searchQuery) para filtrar os drinks disponíveis pelo nome.

Crie uma função assíncrona toggleDrink(drinkId: number, isSelected: boolean).

Se isSelected for true, chame a Server Action removeDrinkFromEvent(eventId, drinkId).

Se for false, chame addDrinkToEvent(eventId, drinkId) (importando do seu arquivo de actions).

Em ambos os casos, finalize chamando router.refresh().

Layout da Vitrine (Grid de Cards):

Exiba o resumo atual (total de drinks, tipos e proporção) no topo.

Logo abaixo, o Input de busca.

Abaixo da busca, renderize um <div className="grid gap-4 sm:grid-cols-2 lg:grid-cols-3"> com os itens de availableDrinks filtrados pela busca.

Filtre a lista principal para renderizar apenas os drinks mestres (parentId === null).

Renderização Inteligente dos Cards (Independentes vs Pastas):

Drink Independente (Sem variações):

Verifique se ele está no evento: const isSelected = drinks.some(d => d.drinkId === drink.id);

Transforme o <Card> inteiro em um botão clicável (cursor-pointer transition-all active:scale-95).

Design Selecionado: border-primary bg-primary/5 shadow-sm. Adicione um ícone <CheckCircle2 className="text-primary"/> no cabeçalho.

Design Não Selecionado: Estilo padrão do shadcn, com opacidade levemente reduzida para não chamar tanta atenção.

No onClick do card, chame toggleDrink(drink.id, isSelected).

Drink Pasta (Com Variações/Filhos):

O Card Pai em si não deve ser selecionável (pois pais não vão pro evento).

No <CardHeader>, exiba o nome do Drink Pai (ex: 'Caipifruta').

No <CardContent>, renderize as variações como uma nuvem de botões (Tags/Badges clicáveis).

Use <div className="flex flex-wrap gap-2">. Para cada variante, crie um <Badge> ou <Button size="sm" variant={isSelected ? "default" : "outline"}>.

A lógica de isSelected e o onClick={() => toggleDrink(variant.id, isSelected)} se aplica individualmente a cada variante dentro deste card.

Polimento UI:

Mantenha o código limpo usando componentes do shadcn/ui.

Adicione um indicador visual de 'Loading' (ex: um overlay ou mudando o cursor) durante o clique usando useTransition do React, para evitar que o usuário clique várias vezes enquanto a Server Action roda.
